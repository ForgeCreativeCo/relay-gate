# Relay Gate — Region 01: Dead City

A tilted top-down shooter built with Babylon.js. Everything (map, models, textures) is generated by code; there are no image or model files.

## Running it on your computer

The game uses JavaScript modules, so it has to be served by a small local web server. Double-clicking `index.html` won't work (browsers block modules opened straight from disk).

Pick one:

- **Python** (installed on most Macs and Linux machines): open a terminal in this folder and run
  `python3 -m http.server 8000`
  then visit http://localhost:8000
- **VS Code**: install the "Live Server" extension, right-click `index.html`, choose "Open with Live Server".
- **Node**: `npx serve .`

You need an internet connection the first time, because Babylon.js and the fonts load from a CDN.

## Saving

Inside Claude, progress saves to your account. Run anywhere else, it saves to that browser's local storage instead, automatically.

## Files

| File | What's in it |
|---|---|
| `index.html` | Page layout, HUD, menus and all styling |
| `js/main.js` | Startup, lighting, post-processing, the frame loop, title screen |
| `js/core.js` | Shared game state and helpers (random, collision, line of sight) |
| `js/tex.js` | Procedural textures, materials and the Ash & Neon colour palette |
| `js/geo.js` | Geometry builder (boxes, prisms, cylinders) |
| `js/fx.js` | Particles: ash, fire, sparks, explosions, smoke |
| `js/region1.js` | The Dead City map: streets, ruins, props, the relay gate |
| `js/actors.js` | Player, Mara and raiders |
| `js/machines.js` | Drones, Hunter Walkers and the Warden boss |
| `js/combat.js` | Factions, projectiles, damage |
| `js/loot.js` | Weapon and armour generation, tiers, perks, drops |
| `js/game.js` | Encounters, objectives, checkpoints, interactions |
| `js/ui.js` | HUD, pack screen, menu, end card |
| `js/input.js` | Click/tap commands and keyboard shortcuts |
| `js/nav.js` | Pathfinding for click-to-move |
| `js/save.js` | Saving and loading |

## Controls

Right-click to walk somewhere (hold to keep steering; right-click Mara, the stash or the gate to walk over and use it) · hold left-click to fire: the gun locks on to the nearest threat in range by itself (point at an enemy, or a part of a walker, to aim there instead; with nothing in range it fires toward the cursor) · guns never need reloading · S stop · T next part · Space dodge toward the cursor · Q swap · E use · I pack · C command Mara · Esc menu. On a phone, tap the ground to move and tap an enemy to lock on; the gun fires by itself at your target or the nearest threat. Dodge, Swap and Use buttons appear on screen.
